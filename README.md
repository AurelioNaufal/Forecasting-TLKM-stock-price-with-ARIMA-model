# 📈 Forecasting TLKM Stock Price

## 📌 Project Overview
A time-series forecasting project aiming to predict the stock price of **Telkom Indonesia (TLKM)**. This project utilizes **R Software** to build and evaluate ARIMA models.

## 🧮 Workflow
1. **Stationarity Test:** Applied Augmented Dickey-Fuller tests.
2. **Diagnostics:** Analyzed Autocorrelation (ACF) and Partial Autocorrelation (PACF) plots.
3. **Model Selection:** Iteratively tested ARIMA parameters to identify the model with the lowest error metrics.
